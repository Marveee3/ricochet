# Ricochet — AUTO-GUN

Ретро-аркада (160×144, 8-bit). Пушка стреляет сама, стена живая, из краёв лезут шипы — ты просто уклоняешься и живешь как можно дольше.

## Играть

- GitHub Pages: <https://marveee3.github.io/ricochet/>
- Itch.io: <https://marveee3.itch.io/ricochet>

Игра запускается прямо в браузере — сервер не нужен. Открой `index.html` или:

```sh
python3 -m http.server 8080
```

## Управление

| Устройство | Ввод |
| --- | --- |
| ПК | `WASD` / стрелки — движение, `Space` — старт, ЛКМ — джойстик |
| Телефон | драг пальцем в любой точке экрана, тап — старт/рестарт |

## Что внутри

- **`script.js`** — вся игра: физика упругой стены (verlet-частицы), автопушка, цели, шипы, мягкая очистка оверлейного текста, звёздное поле, весь-экран джойстик (тач + мышь).
- **`index.html` / `styles.css`** — игровой канвас 160×144 и раскладка (канвас + фоновый слой звёзд в letterbox-полосах).

## Версии

В истории сохранены снимки из архивов:

- **v0.1** — база: стена, пушка, цели, шипы, HUD, меню/game over, мягкий клининг текста, рекорд.
- **v0.2** — мобильное управление: виртуальный джойстик, тап-старт.
- **v0.3** — весь экран: звёзды в полосах и углах, джойстик из любой точки (тач + ЛКМ), единый масштаб звёзд, фикс направлений.
